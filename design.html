Component guide

Direction A · Timetable, frozen. Values here are the rendered form of src/theme/tokens.ts, which is the source of truth — this page is the specimen, DESIGN.md is the reasoning. Every specimen below is shown in both appearances, pinned, because that is the only way to catch a token that works in one and not the other.

01

Colour

Eight roles. Light is primary; dark is designed, not inverted. Every pair that occurs in the UI is asserted at WCAG AA in src/theme/parity.test.ts — a change that drops text below 4.5:1 fails the build.

Light
Dark
Two rules that are easy to break. now marks the present moment on the timetable and nothing else — it is not an error colour and never marks a missed prayer, because the tracker reads as consistency, never as debt. And the accent flips role between appearances: dark fill with pale text on light, light fill with near-black on dark. That is why accentInk is its own token instead of a hardcoded white.

03

The Arabic rendering rules

These are not style preferences. Breaking them produces text that is not merely ugly but wrong, and a wrong letter in the mushaf is an existential bug for this product.

Correct · letterSpacing 0

إِنَّ مَعَ ٱلْعُسْرِ يُسْرًا

Letters join. This is the only acceptable rendering.
Broken · letterSpacing .08em

إِنَّ مَعَ ٱلْعُسْرِ يُسْرًا

Tracking prises the joins apart. Asserted against in parity.test.ts; there is no “just a little”.
Also binding: one <Text> per line — never split a line into multiple Text nodes to style part of it, because shaping happens per node and the join at the boundary is lost. Highlights are absolutely-positioned <View>s behind the text, never a background on a nested Text. React Native shapes through CoreText and Minikin, which handle Arabic correctly — do not import workarounds for the Flutter shaping bugs.

Screen gutter 16. Row padding 12, which with 15pt text gives a 44pt row — Apple’s minimum touch target. Timetable rows are tappable (tap a prayer to mark it); this started at 8 and was corrected once they became interactive. The next-prayer field breaks the gutter and runs full-bleed, because on a printed timetable the header band does too.

Motion

The timetable does not move. The only motion in the system is a 180ms ease-out cross-fade when a time rolls over — short enough to read as a print refresh rather than an animation. Under Reduce Motion every duration drops to 0. No shimmer, no spring, no parallax.

07

Where these values come from

One source, three generated outputs. The widget and both shield extensions run in their own processes and cannot reach the JS bundle, so their colours are compiled in.

src/theme/tokens.ts ──npm run gen:theme──> targets/widget/Theme.swift
                    └──────────────────────> modules/rakat-blocking/.../values/colors.xml
                                           └ ...values-night/colors.xml
Never hand-edit a generated file. npm test re-runs the generator in memory and diffs against disk, so drift in either direction fails with the message run: npm run gen:theme. Pattern lifted from noreeels’ ThemeTokenParityTest.kt, with the expectation table replaced by the generator itself so there is no third place to update.
Nothing with Arabic on it ships without the reviewer’s sign-off. Every Arabic string on this page — including the German translation line, which must be checked byte-for-byte against QuranEnc deu_frankbubenheima 1.1.0 — is tracked in REVIEW.md.
